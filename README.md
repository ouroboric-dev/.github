# .github

Organisation-wide defaults for [ouroboric-dev](https://github.com/ouroboric-dev):

- `profile/README.md`: the organisation's public profile page.
- Default community health files (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`,
  `SUPPORT.md`), issue forms and the pull request template. They apply to every repository that
  doesn't define its own.

**Every change here is organisation-wide.** A broken issue form blocks issue filing in every
repository that relies on it; a wrong security contact misroutes vulnerability reports for every
project. Keep this repository small, change it rarely, and have a human review every change.

Company documents, standards and the journal live in
[ouroboric](https://github.com/ouroboric-dev/ouroboric), not here.
