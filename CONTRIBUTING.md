# Contributing

Thank you for your interest. **Ouroboric is read-only for now:** issues and pull requests are closed
while the project sets up its issue standards and protections.

- **Questions and ideas:** use [Discussions](https://github.com/ouroboric-dev/ouroboric/discussions).
- **Security reports:** see [SECURITY.md](SECURITY.md). Never post them in Discussions.

When contributions open:

- Work will start from issues that pass the Definition of Ready, following
  [spec-driven development](https://github.com/ouroboric-dev/ouroboric/blob/main/docs/4-ways-of-working/spec-driven-development.md).
- Contributors will sign a **contributor licence agreement**, so that the project can keep offering
  its code under more than one licence.
