# AGENTS.md

This repository sets organisation-wide defaults. Every change affects every repository in
`ouroboric-dev`.

- Do not change files here without a human-approved task.
- Do not add company documents here. They belong in the `ouroboric` repository.
- Keep issue form field labels stable. Readiness checks parse the `### <Label>` headings.
- Never put contacts, keys or personal data in these files unless a human provides them.
